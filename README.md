# 上班族離職衝動計｜加權指數版
用臺灣證交所加權指數與上市類股漲跌做成的上班族小遊戲（單一 HTML 檔，資料內嵌）。
線上版：https://johnny761031.github.io/taiex-office/
資料來源：臺灣證券交易所 MI_INDEX（資料日期見頁面上方）。純屬娛樂，非投資建議。

## 即時更新
- 更新程式 `update_data.py`：週一至五盤中（台北 09:00–13:59）約每 3 分鐘、收盤後再抓正式收盤表，更新 `data.json`（目前由外部排程執行）。
- 網頁每 60 秒重新讀取 `data.json`，不用重新整理；抓取失敗時保留最後一筆成功資料並顯示資料時間。
- 盤中漲跌幅為證交所 MIS 即時現值對昨收計算；盤中不含綠能環保、數位雲端、運動休閒、居家生活四類（即時 API 未提供）。
